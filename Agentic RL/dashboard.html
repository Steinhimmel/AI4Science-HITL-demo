A guide to this console

界面模块说明

每个区域在 HITL 流程中承担不同职责：连接负责操作者身份，审批区把人的决定变成执行门槛，数据和记录区则帮助操作员观察与追溯结果。

MODULE 01

操作者连接

输入本地服务生成的操作者凭据，建立有权限的控制台会话。Agent 使用另一身份；不要把这里的凭据交给模型。

MODULE 02

设备状态与安全控制

显示模拟服务状态、联锁反馈和异常原因。人工复位只恢复到可操作状态；停止和软件急停用于中断流程，其中急停会锁存状态。

MODULE 03

实验计划与人工审批

参数表单生成待审扫描计划。审批卡片展示参数、计划标识和摘要；操作员可批准、拒绝或撤销。批准与启动分开，计划变化后不能沿用旧批准。

MODULE 04

模拟联锁

舱门和冷却开关模拟设备保护条件，用来验证不安全状态下的拒绝启动和停止行为。这些开关不是实际传感器，也不能代表硬件保护。

MODULE 05

数据图表与文件

图表展示模拟或导入的角度—强度数据；CSV / JSON 用于导出或回放。导入文件标记为未验证数据，不是实验室测量结果。

MODULE 06

操作与审批记录

显示最近的提案、审批、启动、停止和安全事件，为演示提供可追踪证据。它是本地原型日志，不等同于防篡改的生产审计系统。

演示建议：先提交并拒绝一个计划，观察设备不启动；再批准一个合规计划并启动，观察数据回流。也可以切换一个模拟联锁开关，展示异常如何阻止执行。页面中的扫描信号、设备状态和安全开关均为软件模拟，不代表真实仪器或实验结果。

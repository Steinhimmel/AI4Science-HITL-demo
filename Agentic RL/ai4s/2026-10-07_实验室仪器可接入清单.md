## 3. Windows、macOS 与 Wi-Fi 接入方式

- **串口设备**：仪器 → USB-RS232 / USB-RS485 转换器 → Windows 或 Mac。转换器须匹配仪器电气接口，软件须匹配协议。
- **需要 Wi-Fi 的串口设备**：仪器 → 串口网络网关 → 局域网 → 电脑。网关只转换传输方式，不会让没有协议的仪器自动获得可编程控制能力。
- **IVIUM 及依赖 Windows 厂家软件的设备**：Windows 电脑连接仪器、运行驱动或控制服务，Mac 通过局域网调用该服务。这是建议架构，尚未实现。
- **东华、天美等厂家软件设备**：先用厂家软件打通连接，再核对开放接口；能在软件里操作不代表已经能用 Python 直接控制。

本清单没有确认这些现有仪器原生内置 Wi-Fi。加装网关属于后续接入方案。

## 4. 接入前必须补齐的信息

1. 整机准确型号、生产年份及控制器型号。
2. 通信模块是否已安装，端口类型、引脚定义及接线要求。
3. 通信协议、波特率、设备地址、寄存器表，或 SDK / DLL 文档及示例代码。
4. 分别确认：读取实时值、修改设定值、启动 / 停止、读取运行状态和报警。
5. 核对远程控制模式、断线行为，以及原机联锁在远程模式下是否正常保留。

可直接发给厂家的询问文字：

> 我们计划用自写程序连接现有仪器，需要读取实时值、修改设定值、启动 / 停止并读取运行状态。请确认该机器是否已安装可用的通信模块，并提供端口及引脚说明、通信协议 / 寄存器表或 SDK / DLL、可运行的示例代码，以及支持的操作系统。请分别说明只读数据和可写控制的范围；仅有上位机软件或数据导出功能不能满足全部需求。

## 7. HITL 最小演示建议

### 首选：IVIUM + pyvium 做“人工放行后执行实验”

清单中的 IVIUM 是当前最适合展示完整 Human-in-the-Loop（HITL）闭环的候选：开源项目 [Gnpd/pyvium](https://github.com/Gnpd/pyvium) 使用 IviumSoft 官方 DLL，提供了从加载 `.imf` 方法、修改参数、启动、监控到中止实验的 [Method Mode Notebook](https://github.com/Gnpd/pyvium/blob/main/notebooks/06_method_mode.ipynb)。项目采用 Apache-2.0 许可证。Windows 需安装兼容版本的 IviumSoft；本清单所列仪器型号、DLL 与实机连接仍须核对，尚未实机验证。

建议 demo 流程：

1. **AI 提议，不直接操作仪器**：根据任务生成实验方法和参数候选，只允许使用实验室预先批准的方法模板及参数白名单。
2. **程序硬校验并展示**：校验参数是否在 SOP 设定的安全范围内；给操作员展示方法名、参数变更前后值、样品/电极标识和预计步骤。超范围或缺少必要信息时拒绝进入审批，不允许人工点击绕过硬限制。
3. **人工明确放行**：操作员确认样品与仪器状态后，对展示的这一份确定参数计划点击“批准运行”；审批记录绑定计划内容及方法文件版本/哈希，计划改变后必须重新审批。
4. **获批后才调用设备 API**：执行服务仅接受已批准的计划，再调用 `pyvium` 的 `load_method`、允许范围内的 `set_method_parameter` 和 `start_method`；AI 不能直接调用 DLL 或绕过审批入口。
5. **运行中监督与留痕**：显示运行状态和测量数据；对预先由实验室定义的停止条件触发告警，并提供人工中止入口。保存提议、硬校验结果、审批人/时间、实际执行参数、运行结果及中止记录。API 的程序中止不能替代仪器联锁或实验室应急流程。

这样可以演示 HITL 的实质效果：**AI 负责生成候选方案，人负责对具体且可检查的方案授权，确定性策略拦截越界参数，运行过程可由人监督和中止**。演示时可注入一个越界参数，确认系统在审批前拦截；再用实验室批准的模板完成一次正常流程，展示审批记录与运行数据对应。用“被拦截的越界提议数、批准/拒绝数、运行中止数、审批耗时、参数与审计记录一致率”评估效果；切勿仅以成功运行一次作为 HITL 有效的证据。

### 低风险备选：MT-SICS 天平做读数确认

若暂时没有可用的 IVIUM 实机，可考虑 [PyLabRobot 的 MTSICSDriver 与天平示例](https://github.com/PyLabRobot/pylabrobot/tree/main/docs/user_guide/mettler_toledo/scales)。项目示例针对支持 MT-SICS 的设备，并注明 WXS205SDU/15 的硬件验证；这不等于清单中任意梅特勒天平都已验证。可先做“读取稳定重量 → AI 给出称量判断/下一步建议 → 人确认后记录或发起获准动作”的窄 demo。先限制为只读采集；清零、去皮等写操作须另行检查设备所支持的命令，并纳入同样的审批和日志。该路线接入风险较低，但展示的实验闭环和安全放行能力弱于 IVIUM 方法运行 demo。
